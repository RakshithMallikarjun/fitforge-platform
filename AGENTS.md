- Use src/lib/copy.ts for counted labels and segment-aware navigation matching so plural forms and active links stay consistent.
- Console and member email outreach uses ContactByEmail with real mailto anchors and shared Gmail/copy/fallback handling; platform overview resolves active gym admins through existing guarded contact reads, never member data.
- Protected console pending states use public-safe ConsoleLoading chrome, then real shells with content skeletons until access checks finish; never render protected content before authorization.
- The shared Sonner wrapper enforces wall-clock expiry for long error notifications so hovering cannot keep them indefinitely.
- Render platform audit details through src/lib/audit-summary.ts with an expandable raw view so changes remain readable without losing the original data.
- Each console content route owns metadata generated by src/lib/page-head.ts to keep titles unique and social descriptions complete.
- Admins and trainers share the exercise library under /admin/exercises; keep detail sheets nested there and filters in URL search so shared links and reloads preserve context.
- Exercise library workout reads and additions use authenticated, gym-scoped server functions with explicit assigned-member checks for trainers; retain existing RLS as the final authorization boundary.
- Reusing a template in the plan builder passes templateId and copies values without database row IDs, so Save creates a new plan rather than editing the source.
- Gym addresses derive from authoritative gym slugs through public-config helpers; hostname is navigation context only, while existing authenticated gym reads and RLS remain the authorization boundary. Never transfer sessions or callback tokens across origins; root forwarding requires signing in again on the gym host.
